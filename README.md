# Feigen Advisors — design preview

A design proposal for [feigenadvisors.com](https://feigenadvisors.com), prepared
by PAPINGU. Five pages: Home, About, Team, Research, News.

**Live preview:** https://granittemaj.github.io/feigen-advisors-preview/

## What this is

A static mockup, not the live site and not a deployed build. Content, team bios
and the TSR series are the firm's real copy, so the direction can be judged
against what the site actually says rather than placeholder text.

Architectural photography is licensed stand-in imagery under the
[Unsplash licence](https://unsplash.com/license), standing in for a final
selection. Portraits are the firm's own files, corrected for consistent white
balance and exposure.

Search engines are excluded (`robots.txt` + `noindex`) because the page carries
Feigen branding and is not the live site.
